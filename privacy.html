Privacy Policy

Last updated: 2026-10-21

Health Pipeline is a personal data sync tool used only by its owner.

Data accessed

The app reads only the owner's own Google Health data, with read-only access. Data categories:

  • Sleep
  • Heart rate and heart rate variability (HRV)
  • Resting heart rate
  • Skin temperature
  • Blood oxygen (SpO2)
  • Steps

How data is used

Data is used only for the owner's own training and health analysis. It is not used for advertising, and it is not used to train generalized AI or machine learning models.

Storage, retention and deletion

Data is stored only on the owner's own machine. It is not uploaded to any other server. The owner keeps it for as long as they choose and deletes it themselves.

Access can be revoked at any time at https://myaccount.google.com/permissions.

Sharing

Data is never sold, and is never shared with or transferred to any third party.

Google API Services User Data Policy

Health Pipeline's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
